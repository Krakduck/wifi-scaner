# 📶 ESP32 Wi-Fi Scanner & Analyzer

Универсальный сканер Wi-Fi сетей на базе микроконтроллера ESP32 и фреймворка PlatformIO. Проект разделен на две основные версии (ветки), реализующие разный способ взаимодействия с устройством.

## 🔀 Версии проекта (Ветки)

### 1. main — Интерфейс на физическом дисплее
Версия для сборки автономного портативного устройства со встроенным экраном.

* **Назначение:** Отображение списка доступных Wi-Fi сетей, уровня сигнала (RSSI), типа шифрования и используемых каналов на локальном дисплее.
* **Ключевые модули:**
  * `src/main.cpp` — основной цикл и логика приложения.
  * `src/network_scanner.cpp` / `.h` — модуль сканирования радиоэфира.
  * `src/display_ui.cpp` / `.h` — рендеринг и логика пользовательского интерфейса на экране.

### 2. web-control — Веб-интерфейс (Web Control)
Версия для дистанционного управления устройством через браузер без использования физического экрана.

* **Назначение:** ESP32 поднимает точку доступа или подключается к существующей сети и запускает HTTP-сервер. Просмотр результатов сканирования и управление устройством происходят через веб-страницу.
* **Ключевые модули:**
  * `src/main.cpp` — инициализация сетевых сервисов и сервера.
  * `src/network_scanner.cpp` / `.h` — модуль сканирования радиоэфира.
  * `src/web_server.cpp` / `.h` — обработка HTTP-запросов и работа веб-сервера.
